Этот проект представляет собой базу данных для управления клиническими исследованиями, 
разработанную с использованием SQL. Система предназначена для хранения и обработки 
данных о пациентах, исследованиях, медицинских препаратах и результатах анализов.

Тема проекта: "Лаборатория клинических исследований"
Краткое описание таблиц:

Результаты (моча): Данные анализов мочи для оценки состояния здоровья пациентов.
Лаборанты: Информация о сотрудниках, проводящих анализы.
Пациенты: Данные о пациентах.
Образцы: Информация о биологических образцах для анализа.
Эксперименты: Данные о проводимых исследованиях.
Оборудование: Учет лабораторного оборудования.
Результаты (кровь): Данные анализов крови для диагностики.
